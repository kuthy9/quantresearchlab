**Goal:** Replace the mechanical Brain with a Sleep-Controller-gated LLM Brain that keeps an incremental `BrainState`, names only Eye object aliases, and journals every step in a hash chain that replays without hindsight.

**Architecture:** The Eye is unchanged. `brain/core/eye_view.py` turns each `MarketObservation` into an `EyeContext` with per-episode object aliases; `sleep_controller.py` decides WAKE / UPDATE / TICK from the Eye's transition events; `main_brain.py` builds the `LLMInput`, calls DeepSeek through `llm_client.py`, parses the strict-JSON `LLMUpdate` and hands it to the pure `reducer.py`; `runtime.py` runs the SLEEP ↔ ACTIVE machine and writes `journal.py` records. The old kNN Brain, research gates, decision/risk and the un-importable engine are deleted.

**Tech Stack:** Python 3.12, pandas, stdlib `urllib`/`json`/`hashlib` (no new dependency), pytest. DeepSeek chat completions (`deepseek-flash`, JSON mode) via `DEEPSEEK_API_KEY`.

```python
# brain/core/eye_view.py
"""What the Brain reads from one Eye observation.

The only Brain module that touches Eye types."""
from __future__ import annotations

from contract.eye import LiquidityInventoryLifecycle, MarketObservation


def visible_liquidity_ids(observation: MarketObservation) -> set[str]:
    """Inventory items a downstream consumer may act on: VISIBLE, confirmed by
    ``asof``, and not published twice with different geometry."""
    seen: dict[str, tuple[float, float, float]] = {}
    ambiguous: set[str] = set()
    for item in observation.liquidity_inventory:
        if item.lifecycle is not LiquidityInventoryLifecycle.VISIBLE or item.confirmed_at > observation.asof:
            continue
        geometry = (float(item.price), float(item.lower_bound), float(item.upper_bound))
        prior = seen.get(item.item_id)
        if prior is None:
            seen[item.item_id] = geometry
        elif prior != geometry:
            ambiguous.add(item.item_id)
    return set(seen) - ambiguous
```
