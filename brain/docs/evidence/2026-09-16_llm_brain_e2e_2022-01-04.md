## What the run changed in the code

- `fc9bb73`: `max_tokens` 8192 → 32768; a reply with `finish_reason=length`
  is refused as malformed with a message naming the cap; the journal keeps
  the repair reason and the refused reply (this run predates that, so its
  25 repairs carry no reason).
- `0bf0318` (before this run): TLS verified against certifi — the first
  attempt at this window made 80 calls and received nothing because
  python.org's Python ships no CA bundle.
- `e159074`: an empty-content incident replays as the same refusal; a
  replay that diverges from its journal reports a mismatch instead of
  crashing.
- The prompt now states the LONG / SHORT geometry rule the reducer enforces
  (all seven refused opportunities put a SHORT target above its entry).

## Open

- The LLM never returned to SLEEP on this window; the full
  SLEEP → WAKE → UPDATE → TICK → SLEEP cycle is proved by
  `brain/tests/test_runtime.py` and `test_replay.py` on the synthetic Eye,
  not yet by a real-model run.
- Evidence parked in `unresolved` by an incident bar can only leave through a
  RESOLVE verdict, one per new evidence item; 112 such items accumulated here
  and would block sleep even if the model asked for it.
- 25 repairs in 45 steps is the model's JSON discipline under an 8k cap;
  re-measure at 32k with the repair reasons now journaled.
